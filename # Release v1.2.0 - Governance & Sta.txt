# Release v1.2.0 - Governance & Stability Engine

## Overview
This release marks the stable production-ready iteration of the No-Drift API. Version 1.2.0 introduces a formal governance framework, optimized mathematical drift detection, and a unified Streamlit dashboard for real-time model monitoring.

## Key Features & Improvements
*   **PSI Stability Engine:** Implemented a robust Population Stability Index (PSI) calculation module with mathematical smoothing to prevent runtime exceptions.
*   **Unified Dashboard:** Integrated the dashboard into `app.py`, optimized for Hugging Face Spaces (Streamlit SDK).
*   **Governance Gateway:** Added strict schema validation and structural circuit-breaker logic to the `/api/v1/verify-drift` endpoint.
*   **CI/CD Pipeline:** Refactored deployment workflows for seamless GitHub-to-Hugging Face synchronization.
*   **Testing Suite:** Included `run_all_tests.py` for comprehensive E2E validation.
